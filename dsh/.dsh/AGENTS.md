## Git Commit Guidelines
- Do NOT add any `Co-authored-by:` trailers.
- Do NOT include any promotional footers in commit messages.
- Always commit under the current local Git user author identity.

## Pull Request Guidelines
- Keep emoji/icons to a minimum in PR titles and descriptions.
- Do NOT add any "Generated with ..." or similar promotional footers to PR descriptions.

## Superpowers Bootstrap

Before starting a code task expected to take more than ~5 minutes —
implementing features, fixing bugs, refactoring, or anything needing a plan
— load the `using-superpowers` skill via the `skill` tool and follow it to
pick the matching skill (brainstorming, systematic-debugging,
test-driven-development, writing-plans, executing-plans,
verification-before-completion). Skip the bootstrap for quick questions,
small edits, and read-only lookups. Tool names resolve per
`using-superpowers/references/dsh-tools.md`.
